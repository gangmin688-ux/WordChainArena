# 끝말잇기 1v1

사용자가 제공한 `끄글_모든단어`와 `끄글_패배단어` 데이터를 이용한 1v1 끝말잇기 사이트입니다.

## 실행
- `index.html`, `words.json`, `loss.json`, `index.json`을 같은 폴더에 둡니다.
- 브라우저에서 직접 `file://`로 열기보다 정적 웹서버로 여는 것을 권장합니다.
- VS Code의 Live Server, GitHub Pages, Cloudflare Pages 등으로 올릴 수 있습니다.
- 온라인 1v1은 PeerJS를 사용하므로 인터넷 연결이 필요합니다.
- 같은 기기 1v1은 별도 서버 없이 사용할 수 있습니다.

## 규칙
- 제공된 모든단어 파일에 있는 단어만 인정합니다.
- 이전 단어의 마지막 글자와 다음 단어의 첫 글자가 같아야 합니다.
- 중복 단어는 사용할 수 없습니다.
- 패배단어는 기본적으로 경고만 표시합니다. 설정에서 금지할 수도 있습니다.
