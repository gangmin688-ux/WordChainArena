WordChainArena (끝말잇기 대전) - 사용 설명서
================================

[포함된 파일]
- index.html   : 게임 실행 파일 (더블클릭으로 브라우저에서 바로 실행)
- style.css    : 디자인
- words.js     : 단어 사전(약 26만 단어) + 두음법칙 매핑 + 힌트 데이터 (업로드해주신 4개 파일 기반 자동 생성)
- game.js      : 끝말잇기 규칙 검증 로직
- firebase.js  : 온라인 대전용 Firebase Realtime Database 연동 (REST API 방식)
- app.js       : 화면/UI 컨트롤러

[실행 방법]
index.html 파일을 더블클릭하면 크롬/엣지/사파리 등에서 바로 열립니다.
별도 서버 설치 없이 오프라인(로컬 대전)에서는 그대로 동작합니다.

[모드 안내]
1) 로컬 대전 (한 기기)
   - 2~6명까지 이름을 입력하고 시작하면, 같은 기기를 돌려가며(패스 앤 플레이) 대전할 수 있습니다.
   - 제한시간(기본 30초) 안에 단어를 입력하지 못하면 탈락하며, 한 명만 남으면 게임이 끝납니다.

2) 온라인 대전 (여러 기기, 1:1 / 1:1:1 / 1:1:1:1...)
   - "온라인 방 만들기"를 누르면 4자리 방 코드가 생성됩니다.
   - 다른 기기(각자의 폰/PC)에서 같은 index.html을 열고 "온라인 방 참가" 후 방 코드를 입력하면 됩니다.
   - 방장이 2명 이상 모이면 "게임 시작"을 눌러 진행합니다.
   - Firebase Realtime Database를 사용해 실시간으로 순서/제한시간/단어 기록을 동기화합니다.
     (사용 DB: https://wordchainarena-default-rtdb.asia-southeast1.firebasedatabase.app)

[Firebase 규칙(rules) 설정 - 온라인 대전을 쓰려면 꼭 확인하세요]
이 앱은 별도 API 키 없이 REST 방식으로 /rooms 경로를 읽고 씁니다.
Firebase 콘솔 > Realtime Database > 규칙(Rules)에서 아래처럼 /rooms 경로가
공개 읽기/쓰기로 열려 있어야 정상 동작합니다. (테스트/개인용 용도 기준)

{
  "rules": {
    "rooms": {
      ".read": true,
      ".write": true
    }
  }
}

(접근 제어 기능을 쓰려면 /config 도 같은 방식으로 열어야 합니다)
{ "rules": { "rooms": {".read": true, ".write": true}, "config": {".read": true, ".write": true}, "presence": {".read": true, ".write": true}, "blockedUsers": {".read": true, ".write": true} } }

규칙이 막혀 있으면 "방 생성에 실패했습니다" 같은 오류가 표시됩니다.
(보안이 필요하다면 추후 Firebase Auth를 붙여 uid 기반 규칙으로 강화할 수 있습니다.)

[게임 규칙]
- 이전 단어의 마지막 글자로 시작하는, 아직 사용하지 않은 단어를 입력해야 합니다.
- 두음법칙(예: 려→여, 라→나 등)은 업로드해주신 데이터 기반으로 자동 인식되어
  '려'로 끝나도 '여'로 시작하는 단어를 낼 수 있습니다.
- 제한시간 안에 입력하지 못하거나 "포기"를 누르면 탈락합니다.
- "힌트" 버튼을 누르면 업로드해주신 필수 공격 단어 데이터를 참고해 이어갈 수 있는 단어를 하나 알려줍니다.
- 사전은 업로드해주신 [WordChainArena_모든단어] 파일 전체(약 26만 개)를 기준으로 판정합니다.

[알려진 한계]
- 온라인 모드는 REST 폴링(약 1.2초 간격) 방식이라 초 단위의 아주 약간의 지연이 있을 수 있습니다.
- 여러 기기가 정확히 같은 순간에 시간 초과를 처리하려 할 경우 드물게 동기화 오차가 생길 수 있습니다.
- 중간에 나간 플레이어를 자동으로 감지해 처리하지는 않습니다(제한시간 초과로만 탈락 처리).

[v14 추가 – 로그인/회원가입 + 코인 판돈 + 랭킹]
- 메인 화면에 "로그인 / 회원가입" 추가. 온라인 대전은 로그인해야 이용할 수 있습니다.
  회원가입 시 시작 코인(기본 1,000개)이 지급됩니다.
- 온라인 "방 만들기" 화면에서 "판돈(인당 베팅 코인)"을 정할 수 있습니다(0이면 무료로 재미로만 플레이).
  방장이 "게임 시작"을 누르면 참가자 전원의 코인이 지정한 만큼 빠져나가는 모션이 나오고,
  게임이 끝나면 이긴 사람이 판돈 전부를 가져가는 모션과 함께 코인이 지급됩니다.
  누군가 코인이 부족하면 시작되지 않고 안내 메시지가 표시됩니다.
- 메인 화면 "🏆 랭킹"에서 전체 플레이어의 보유 코인 순위를 볼 수 있습니다.
- 로컬 대전(같은 기기로 돌려가며 하는 모드)은 여러 사람이 한 기기를 같이 쓰기 때문에
  코인 판돈을 적용하지 않았습니다(온라인 대전에서만 지원).

  이제 IP가 아니라 로그인 아이디 기준으로 차단합니다. 현재 접속 중인 사용자 목록에서 바로 차단하거나,
  아이디를 직접 입력해 차단할 수 있습니다. 차단된 아이디로 로그인한 상태로 접속하면 전체 잠금 화면이 표시됩니다.
  로그인하지 않은 손님(게스트)은 계정이 없어 차단 대상이 되지 않으며, 로컬(vs 컴퓨터) 플레이에는 영향이 없습니다.
  (IP 기반 차단·접속자 조회 기능은 제거되었습니다. Firebase 규칙에서 기존 /blocked 대신 /blockedUsers 경로를 열어야 합니다.)
- admin.html "💰 코인 관리" 탭 추가: 아이디를 조회해 보유 코인을 확인하고, 원하는 만큼 지급/차감하거나
  코인을 원하는 값으로 직접 설정할 수 있습니다. 전체 사용자 코인 순위도 함께 보여주며, 목록에서 "선택"을 누르면
  바로 그 사용자를 조회 칸에 채워줍니다.

  "🏆 랭킹" 화면에서 본인 닉네임 오른쪽에 "닉네임 [칭호]" 형태로 표시됩니다.

[보안/이용 안내 – 중요]
- 이 앱은 별도 서버 없이 Firebase Realtime Database에 REST로 직접 붙는 구조라서,
  로그인 비밀번호를 서버에서 검증하지 못하고 브라우저가 직접 비교합니다.
  DB 규칙이 열려 있으면 누구나 비밀번호 해시를 내려받아 오프라인으로 크랙을 시도할 수 있습니다.
  실제 돈이 걸린 서비스가 아니라 친구끼리 하는 재미용 게임머니 용도로만 사용하고,
  다른 사이트와 같은 비밀번호를 재사용하지 마세요.
- 코인은 전부 이 앱 안에서만 쓰는 가상의 게임머니이며, 실제 현금으로 충전/환전할 수 있는 기능은 없습니다.
- [Firebase 규칙(rules) 설정] 예시에 아래 두 경로를 추가로 열어야 합니다.
  { "rules": { "auth": {".read": true, ".write": true}, "users": {".read": true, ".write": true} } }
